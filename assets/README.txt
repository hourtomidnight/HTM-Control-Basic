Place the following audio files in this folder:

  TimerMusic.mp3   — Background music that plays while the timer runs
  FinaleMusic.mp3  — Music that plays when "You Escaped!" is shown
  ClueSound.mp3    — Short sound that plays when a clue is displayed

Logo image path is set in the Configuration window (F10).
Clues are also entered in the Configuration window — no text file needed.
